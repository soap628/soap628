## 科研与浏览器工具

### 🧬 PrimerCat

把 qPCR 引物设计、CRISPR gRNA 设计、BLAST 与序列工具串成可溯源的工作流程。

[**打开 PrimerCat**](https://primercat.tech) · [源代码](https://github.com/soap628/primercat)

### 📚 Hyrax

PubMed 文献助手，将期刊指标、风险提示、文章筛选、摘要速览与 PMID 导出放进文献浏览流程。

[**查看 Hyrax**](https://github.com/soap628/hyrax)

### 更多工具

- 🔬 [**CHD Explorer**](https://github.com/soap628/CHDB) — 交互探索 CHD1–CHD9 的 ClinVar 变异与 HPO 表型。
- 🧪 [**MED12**](https://github.com/soap628/MED12-) — 连接 AlphaMissense、AlphaFold、ClinVar 与多组学证据。
- 📓 [**Liquun · Web**](https://github.com/soap628/liquun) — 公开的 Web 项目代码，用于本地优先的课题与实验室管理。
- 🔎 [**CHD7 Explorer**](https://github.com/soap628/chd7clinvar) — 较早的 Python 项目，探索变异及蛋白结构域信息。
- 🎯 [**X Focus**](https://github.com/soap628/x-focus-extension) — 实验性的本地优先 Edge 扩展，记录发帖与回复目标。
