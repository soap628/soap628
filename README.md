## Research & browser tools

### 🧬 PrimerCat

Design qPCR primers and CRISPR guides, run BLAST, and work with sequences in an auditable workflow.

[**Open PrimerCat**](https://primercat.tech) · [Source code](https://github.com/soap628/primercat)

### 📚 Hyrax

A PubMed companion that brings journal metrics, risk signals, filters, quick abstracts, and PMID export into literature browsing.

[**Explore Hyrax**](https://github.com/soap628/hyrax)

### More tools

- 🔬 [**CHD Explorer**](https://github.com/soap628/CHDB) — Explore ClinVar variants and HPO phenotypes across CHD1–CHD9.
- 🧪 [**MED12**](https://github.com/soap628/MED12-) — Connect AlphaMissense, AlphaFold, ClinVar, and multi-omics evidence.
- 📓 [**Liquun · Web**](https://github.com/soap628/liquun) — Public web-project code for local-first research and lab organization.
- 🔎 [**CHD7 Explorer**](https://github.com/soap628/chd7clinvar) — An earlier Python project exploring variants and protein-domain context.
- 🎯 [**X Focus**](https://github.com/soap628/x-focus-extension) — An experimental, local-first Edge extension for posting and reply goals.

My background spans wet-lab research, bioinformatics, and software development. I am interested in reproducible research, multi-omics, clinical-variant exploration, and tools that make complex work easier to do.
