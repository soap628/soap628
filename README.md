## Research tools

From molecular-biology utilities to evidence exploration and research records.

| Project | What it helps with |
| :--- | :--- |

| [**CHD7 Explorer**](https://github.com/soap628/chd7clinvar) | An earlier Python project for exploring CHD7 variants and protein-domain context. |

## Research background

My work connects molecular biology, bioinformatics, and product engineering. I am interested in reproducible research, multi-omics integration, clinical-variant exploration, and software that makes complex work easier to navigate.
